**The set selected with the top 33% and with the top 35% is identical.** The selection does not change for any percentile among 20, 25, 30, 33, 35, 40, 45, 50: in that range the percentile cutoff is below 5, so the photographs are selected by the mean threshold alone and the percentile has no effect.
